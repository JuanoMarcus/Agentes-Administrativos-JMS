# Indicadores de control (valor ganado simplificado para consultoría)

Definiciones (usar HH o CLP de manera consistente):

- **BAC** (presupuesto al término) = HH o costo presupuestado total.
- **PV** (valor planificado) = BAC × % de avance planificado a la fecha.
- **EV** (valor ganado) = BAC × % de avance físico real.
- **AC** (costo real) = HH o costo real acumulado.
- **CPI** = EV / AC. **SPI** = EV / PV.
- **EAC** (estimado al término) = AC + (BAC − EV) / CPI (supuesto de eficiencia constante). Presentar también EAC = AC + (BAC − EV) como escenario optimista.
- **VAC** = BAC − EAC.
- **% consumido** = AC / BAC. **Brecha** = % consumido − % avance físico.

## Semáforos

| Indicador | Verde | Amarillo | Rojo |
|---|---|---|---|
| CPI | ≥ 0,95 | 0,85–0,95 | < 0,85 |
| SPI | ≥ 0,95 | 0,85–0,95 | < 0,85 |
| Brecha consumo–avance | ≤ 5 pts | 5–10 pts | > 10 pts |
| Margen estimado vs ofertado | ≥ ofertado − 3 pts | −3 a −8 pts | < −8 pts |

## Indicadores de cartera

- Margen ponderado de la cartera activa.
- HH no facturables cargadas a proyectos (retrabajo, rondas adicionales).
- % de cambios de alcance cobrados vs absorbidos (en HH).
- Proyectos con alerta roja.
