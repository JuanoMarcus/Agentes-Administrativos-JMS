# Estándar documental propuesto para JMS

Ajustar si JMS ya tiene un estándar propio; en ese caso, el del usuario prevalece.

## Codificación de documentos

`[CódigoProyecto]-[Disciplina]-[TipoDoc]-[Correlativo]_Rev[X]`

Ejemplo: `JMS2611-EST-MC-001_RevB`

| Disciplina | Código |

| Hidráulica | HID |
| Sanitaria | SAN |
| Energía / eléctrica | ENE |
| Geomensura | GEO |
| Arquitectura industrial | ARQ |
| Gestión de proyectos | GES |

| Tipo de documento | Código |

| Memoria de cálculo | MC |

| Especificaciones técnicas | ET |

## Revisiones

- Rev A, B, C…: emisiones internas o para revisión del mandante.
- Rev 0: emitido para construcción o versión aprobada.
- Rev 1, 2…: modificaciones posteriores a la Rev 0.
- Cada documento lleva una tabla de control de revisiones: revisión, fecha, descripción, elaboró, revisó, aprobó.

## Formato estándar de informe

Portada (logo, proyecto, mandante, código, revisión, fecha) → tabla de control de revisiones → índice → cuerpo numerado (1, 1.1, 1.1.1) → anexos. Tipografía sans serif 11 pt, tablas con encabezado repetido, figuras y tablas numeradas con título.
